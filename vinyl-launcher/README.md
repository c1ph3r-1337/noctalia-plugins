# Vinyl Launcher

A beautiful, rotational disc app launcher for Noctalia and Quickshell.

## Credits

**Made by c1ph3r-1337**

This plugin features a custom DJ momentum physics system, dynamic scaling, and a fully custom Quickshell UI architecture.

## Installation

Add this plugin to your Noctalia plugins via the store or `plugins.json`. 

To launch, use the IPC command:
```bash
noctalia-shellctl ipc plugin:vinyl-launcher space
```
